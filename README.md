# 🔐 Secure File Encryptor

A modern, browser-based file encryption and decryption application built using **HTML, CSS, and JavaScript**. This project uses the **Web Crypto API** to perform client-side encryption, ensuring your files remain private and secure.

## 🌐 Live Demo

👉 https://shyambalaji27.github.io/Secure-File-Encryptor/#encrypt

---

## 📖 About the Project

Secure File Encryptor is designed to help users securely encrypt and decrypt files directly in their web browser. All cryptographic operations are performed locally using the browser's Web Crypto API, meaning **no files or passwords are uploaded to any server**. Modern browsers provide secure client-side cryptography through the Web Crypto API, making this approach suitable for privacy-focused applications. :contentReference[oaicite:0]{index=0}

This project demonstrates the implementation of browser-based encryption with a clean and responsive user interface, making it an excellent portfolio project for cybersecurity and cloud security enthusiasts.

## 🚀 How to Use

1. Open the website.
2. Select or drag and drop a file.
3. Enter a strong password.
4. Click **Encrypt File**.
5. Download the encrypted file.
6. To decrypt, upload the encrypted file.
7. Enter the same password.
8. Click **Decrypt File**.
9. Download the original file.
